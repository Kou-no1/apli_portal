# まなびたね｜先生の実践ナビ

既存48件のアプリ・準備中ツールを保持し、5つの困りごとと自由検索から活動・指導のコツ・アプリをまとめて探せる入口です。

`index.html` を既存ページへ配置します。活動の共通原稿・検索ロジックは同じドメインの `../activity-portal/catalog.js` と `../activity-portal/core.js` を読み込みます。活動側の更新を先に公開してください。

読み込みに失敗した場合も、既存アプリの検索・カテゴリー絞り込みと活動集へのリンクを残します。既存アプリのリンク先は変更していません。

カテゴリーと困りごと・検索語は組み合わせて使えます。「実践カードをすべて見る」では困りごとと検索語を引き継ぎ、個別カードでは活動集の該当台本を直接開きます。
